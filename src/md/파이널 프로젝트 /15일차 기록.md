### 💡 배운 점

- 옵션 입력칸 리펙토링 문제 해결 과정 (일반 폼 검증(clientErrors)과 옵션 검증(useOptionForm)의 책임을 분리하여 상태 흐름을 단순화)
  문제 원인:
  옵션 관련 에러 상태를 clientErrors.productOptions 와 useOptionForm.error 두 곳에서 각각 관리하고 있어서 상태 동기화 문제가 있었다. 제출 버튼 클릭 시 생성된 에러 메시지가 옵션을 추가하였음에도 불구하고 사라지지 않는 상황이 문제였다.
  이를 해결하기 위해서 옵션 관련 에러 상태를 useOptionForm 내부의 error 상태 하나로 통합하여, 옵션 추가 버튼 검증과 제출 버튼 검증 모두 setError() 를 통해 동일한 상태를 변경하도록 수정하였다. 옵션 추가 성공 시 setError("") 로 에러 메시지가 나타나지 않게 만들었다. 여러개의 상태를 남발하기보다 하나의 커스텀 훅 함수에서 처리할 수 있는 부분들을 통합하여 반환해내주는 것이 오류 표시를 하는데 깔끔했다.

### 😵 어려웠던 점

- 상품등록 페이지 부분은 깔끔하게 코드를 다듬을 필요가 있다. 여러가지 입력칸이 들어가니깐, 이걸 개별로 관리해야 할지 일괄로 관리해야할지, 그리고 클라이언트와 서버측 모두에게 오류를 전달을 해야 할지 하나만 선택해야 할지 고려해야할 부분이 굉장히 많은 것 같다. 이부분을 팀원분들이 보고서 설명해달라고 하면 못한다..
  직접 다 내 머리로 나온 것이 아니기때문에 더욱 설명하기가 어려운 것 같다.
